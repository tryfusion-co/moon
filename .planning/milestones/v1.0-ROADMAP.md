# Milestone v1.0: Moon SolidJS Design System (React → SolidJS Migration)

**Status:** ✅ SHIPPED 2026-06-01
**Phases:** 1-7
**Total Plans:** 32

## Overview

Full in-place migration of the Moon design system from React 19 to SolidJS, republished as `@moondesignsystem/solid@3.0.0` (was `@moondesignsystem/react@2.5.21`). All 37 components (34 source files), the test suite, the Storybook docs site, and the CLI scaffolder were ported to Solid idioms with byte-identical Tailwind class output and a preserved public API (`class` replaces `className` per Solid). Hard cut — `main` is Solid-only; the React package was abandoned.

## Milestone Summary

**Decimal Phases:** None inserted.

**Key Decisions:**
- Port to SolidJS in-place on `main`; rename @moondesignsystem/react → @moondesignsystem/solid; major bump 3.0.0; hard cut (no parallel React track).
- Bundler: vite-lib + vite-plugin-solid (chosen over abandoned tsup-preset-solid); mandatory `solid` export condition via a two-pass build (vite compiled `.js` + esbuild raw-JSX `.jsx`).
- `splitProps`/`mergeProps` for every component (no prop destructuring — enforced by eslint solid/no-destructure).
- Context-shared refs use signal/callback refs (plain `let` is not reactive across context).
- Drawer.Trigger cloneElement → `display:contents` wrapper span (the one non-mechanical translation).
- Chip uncontrolled-toggle divergence accepted as an intentional improvement over the latent React bug.
- Storybook: storybook-solidjs-vite@10, single-form render (no double-wrapper).

**Issues Resolved (caught by code review / integration):**
- CR-01 (Phase 1): the `solid` export condition would have shipped compiled JS, breaking SSR consumers → fixed with the esbuild raw-JSX second pass.
- CR-01 (Phase 4) / CR-02 (Phase 3): Select/Checkbox `onChange` not firing live in Solid → onInput bridges.
- Stale-worktree regression (Phase 7): package.json react revert + Button mangle → excluded during merge.
- 21 ESLint warnings + 2 `as any` casts → cleanup pass (0 warnings).
- FormGroup story missing → added at audit (34/34 story coverage).

**Issues Deferred (v2):**
- ENH-01: idiomatic Solid refinements (children() helper).
- ENH-02: SolidStart SSR consumer verification.
- Real `npm publish` (only dry-run gated) — human/CI action.

**Technical Debt Incurred:** None blocking. All cosmetic lint resolved; esbuild dep made explicit.
