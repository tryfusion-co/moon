Exact D-03 translation (do NOT deviate):
- `import React, { useRef, useState, useEffect, useCallback } from "react"` → `import { createSignal, onMount, onCleanup, splitProps, type Component, type JSX } from "solid-js"`. Keep ChevronLeft/ChevronRight (Solid icons) + `import type { Directions } from "../types"`. Preserve `export type ScrollDirections = Directions`.
- `const reelRef = useRef<HTMLDivElement>(null)` → `let reelRef!: HTMLDivElement;` ; `ref={reelRef}` on the reel div; access as `reelRef` (NOT reelRef.current).
- `const [canScrollStart, setCanScrollStart] = useState(false)` → `createSignal(false)`; in JSX use `disabled={!canScrollStart()}` (getter CALLED).
- `const [canScrollEnd, setCanScrollEnd] = useState(true)` → `createSignal(true)`; `disabled={!canScrollEnd()}`.
- `updateScrollState`/`handleScroll` wrapped in `useCallback(...,[])` → plain functions (drop useCallback entirely). Bodies UNCHANGED except `reelRef.current` → `reelRef`. Keep getComputedStyle/direction/RTL/scrollWidth/clientWidth/scrollBy logic verbatim.
- `useEffect(() => { ... return () => {...} }, [updateScrollState])` → `onMount(() => { const reel = reelRef; if (!reel) return; updateScrollState(); const handleScrollEvent = () => updateScrollState(); const handleResize = () => updateScrollState(); reel.addEventListener("scroll", handleScrollEvent); window.addEventListener("resize", handleResize); onCleanup(() => { reel.removeEventListener("scroll", handleScrollEvent); window.removeEventListener("resize", handleResize); }); });`.
- hasControls conditional: keep `{hasControls && <Control .../>}` (boolean-guarded — fine) or use `<Show>`; ternary/&& is acceptable per Discretion. Note hasControls is now `props.hasControls` (split it).
- Item/Control: splitProps + class not className + {...rest}. Control keeps `onClick={() => onScrollDirection(direction)}`, `aria-label={direction === "previous" ? "Previous" : "Next"}`, and ternary icon `direction === "next" ? <ChevronRight/> : <ChevronLeft/>`.
- `Object.assign(Root, { Item })`; drop displayName.
</interfaces>
