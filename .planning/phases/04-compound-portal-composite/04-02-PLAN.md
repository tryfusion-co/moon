Dropdown.Trigger (D-04) — cloneElement injected `{ tabIndex: 0, role: "button" }` onto an arbitrary child. Solid has no cloneElement; wrap in a layout-invisible span carrying those attributes:
```tsx
const Trigger: Component<{ children?: JSX.Element }> = (props) => {
  const [local] = splitProps(props, ["children"]);
  return (
    <span style={{ display: "contents" }} tabIndex={0} role="button">
      {local.children}
    </span>
  );
};
```
NOTE: display:contents means the span generates no box; tabIndex/role sit on the wrapper (documented divergence — React put them on the child). Zero cloneElement.

Type names to preserve verbatim (from components/index.ts barrel):
- Menu: `MenuSizes`
- Select: `SelectSizes`, `SelectVariants`
- Snackbar: `SnackbarVariants`
- Tooltip: `TooltipPositions` (currently exported from Tooltip.tsx)
