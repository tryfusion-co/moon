Compound pattern (from Alert.tsx — Object.assign is plain JS, carries over unchanged):
```tsx
const Root: Component<RootProps> = (props) => { const [local, rest] = splitProps(props, ["class", ...]); return <div class={mergeClasses("moon-...", local.class)} {...rest}>{local.children}</div>; };
```

- React.ReactNode → JSX.Element ; className → class
