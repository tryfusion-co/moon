<translation_rules>
Per D-03 / PITFALLS #14, when porting legacy React assertions into the Solid atom file:
- `import { render, screen, fireEvent } from "@testing-library/react"` → `from "@solidjs/testing-library"`
- `render(<X/>)` → `render(() => <X/>)` (MANDATORY function-wrapper)
- `jest.fn()` → `vi.fn()`, `jest.spyOn` → `vi.spyOn`; import `{ vi }` from "vitest"
- `className=` in test JSX → `class=`
- Keep jest-dom matchers (`toBeInTheDocument`, `toHaveClass`) — wired via setupTests.
- Rely on @solidjs/testing-library auto-cleanup — do NOT import/call `cleanup`.
- Reactivity is synchronous — assert immediately after `fireEvent`, no `await findBy` unless async.
</translation_rules>
